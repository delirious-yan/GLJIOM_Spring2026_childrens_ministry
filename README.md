# Spring 2026 Children's Ministry Curriculum (GLJIOM)

A responsive, easy-to-use dashboard developed for the Spring 2026 Children's Ministry at GLJIOM. It organizes our 8-week curriculum spanning themes of Disobedience, Forgiveness (Romans 4:7-8), Miracles of Jesus, and Easter (Death & Resurrection).

## Features

- **Table View**: A high-level overview of dates, topics, key points, teaching prompts, and activities.
- **Cheat Sheets (Cards View)**: Quick-reference cards perfect for glancing over right before or during a lesson.
- **Full Plan View**: Deep dive into each lesson's memory verse, discussion questions, and detailed activity instructions.
- **Master Shopping List**: A consolidated checklist of all supplies needed for the entire 8 weeks, grouped by category.
- **Print-Ready**: Optimized for printing directly from the browser, hiding unnecessary UI elements and formatting cleanly.

## Usage

Simply open `index.html` in any modern web browser to view the dashboard. 

If this repository is hosted on GitHub Pages, you can navigate to the live URL to access the curriculum from any device.

## Technologies Used

- HTML5
- JavaScript
- [Tailwind CSS](https://tailwindcss.com/) (via CDN) for styling
